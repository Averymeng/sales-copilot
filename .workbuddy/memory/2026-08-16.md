## 已锁定：线索行业 私信转化链路 指标树（最终版 2026-08-16，参考聚光报表截图）
- **北极星指标 = 消耗**
- **过程量（不呈现给用户）**：封面点击数 → 按钮点击数(=点"立即咨询/留资组件"进私信=私信进线) → 留资数
- **过程指标（呈现）**：
  - 点击率 (CTR) = 封面点击数 ÷ 曝光（或用点击成本 = 消耗÷封面点击数）
  - 按钮率 = 按钮点击数 ÷ 封面点击数
  - 留资率 = 留资数 ÷ 按钮点击数
- **结果指标（呈现）** = **留资成本（CPL，对外统一叫"留资成本"）** = 消耗 / 留资数
- **版位维度**：信息流 + 搜索（各自独立算，mock 数据差异化）
- **参考界面**：聚光平台数据报表（KPI 卡片 + 趋势图 + 多维明细表），用户提供了截图作为 UI 参考

## 📕 《AI项目方法论核心手册》要点（用户提供PDF，2026-08-16，作为本项目方法论依据）
- **五阶段因果链**：01功能梳理(选对问题→功能锚点+MVP边界) → 02技术实现(跑通链路→Workflow或Agent) → 03评测体系(样本/标准/badcase/复测) → 04 AI PRD(收束方案) → 05简历与面试(可信表达)。真实任务→AI介入点→可运行链路→可复测证据→完整方案→可防守表达。
- **Workflow vs Agent 判断（2.1，关键）**：Workflow=步骤能提前排好/路径大致相同/固定节点调固定工具/输入一次按固定路径。Agent=下一步无法预先写死/需调2+工具/工具结果改变后续/需多轮补信息重试重规划/不同case不同路径。**满足≥2项才用Agent；能用固定链路解决先用Workflow，只把真正需动态决策的部分交给Agent。**
